## Scope

Current branch: `fix/apple-mail-linear-backlog-20260731`, based on `main` at
`2d03487`. This lane implements the bounded, draft-safe portions of the active
Apple Mail MCP Linear backlog. It does not send email, create a user-visible
draft, or change the human-only issues.

## Implemented surfaces

- **AGENTIC-995 / AGENTIC-996:** bounded exports can emit raw RFC 822 EML,
  optionally bundle bounded attachments, report exported numeric IDs, and keep
  entire-mailbox pages deterministically newest-first.
- **AGENTIC-1854:** `list_events` accepts a bounded `participant_query` that
  matches attendee names and addresses, plus EventKit organizer metadata where
  available, without adding participant data to list responses.
- **AGENTIC-1192 / AGENTIC-1904 / AGENTIC-1933:** source-message lookup and
  bounded export paths resolve the documented special mailboxes and preserve
  explicit mailbox scoping for replies outside Inbox.
- **AGENTIC-1989 / AGENTIC-1998:** draft deletion rechecks a complete identity
  tuple immediately before mutation; HTML compose body targeting is
  accessibility-role based and discards the exact new compose window on a
  focus failure.
