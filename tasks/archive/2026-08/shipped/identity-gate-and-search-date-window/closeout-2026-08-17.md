## Decisions made

- **The AGENTIC-2356 one-line fix was correctly refused.** Adding `not date_from` to the fast-path guard disables the fast path on essentially every call, because `date_from` is derived from `recent_days` upstream. Implemented the issue's option A (honor the date inside the fast path) instead.
- **The AGENTIC-2355 definition of done was wrong as literally written** for `search/script.py`. "Replace the unbounded fallback with a structured error" assumes the fallback is rare; `messages 1 thru N` raises whenever the mailbox holds fewer than N messages, which is ordinary for small folders and most of a `mailbox="All"` fan-out. A bare structured error would have made every small mailbox report a failure instead of its results. Clamped re-slice first, structured error only if that also fails, silent on count 0. Live-confirmed on three sub-cap mailboxes.
- **Allowlist versus ratchet is structural, not a judgment call.** A domain joins `SYNTHETIC_TEST_DOMAINS` only where an address there is inherently not identity. Every domain where an address *is* identity goes in the per-file ratchet. This is what stops allowlist rot.
- **The gate must never echo the matched value.** Otherwise it becomes a second copy of the leak in scrollback and logs.
- **Identity scan runs first in both tiers.** Cheapest step, and the only one whose miss cannot be undone in the working tree. It was also unreachable behind `run_manifests` whenever artifacts were merely stale, which is how the ordering problem was found.
- **`.agents/` is deliberately in scope.** Skipping it was a 68-file blind spot over this repo's own first-party skill sources. A scanned-file floor assertion now fails if it is re-added.
- **Lint widened to the whole package rather than a list of the four AppleScript-emitting modules.** A hardcoded file list is the same fragility the coverage assertion exists to catch.
- **No version bump.** 3.11.7 is the repo version and untagged; the CHANGELOG check requires the top dated section to equal the pyproject version, so notes fold into 3.11.7 and the `.mcpb` filename stays stable. Cutting 3.11.8 is a release decision to batch.
- **Corrected a duplicate rather than fixing it.** `__init__.py`'s per-module tool counts had drifted to 38 against 41 and nothing gated them; the gated table is in `tools/CLAUDE.md`, so correcting the copy would only re-arm the trap.
